# Project memory

Project-wide lessons that the code, the specs and Git history don't say. Lessons about a single feature live in that feature's own `MEMORY.md`, listed at the end of this file. Every agent reads this file when it starts: Claude Code loads it through `CLAUDE.md`, and `AGENTS.md` tells Codex and the others to read it. A lesson one agent learns is then there for the next one, whichever agent that is.

The rules for this file are in [AGENTS.md](AGENTS.md#project-memory). Keep entries short, dated and true. Once an entry becomes a standing rule, move it into `AGENTS.md` or a `SPEC.md` and delete it here.
